# calluccarpentry.com

The Calluc Carpentry website, published free by GitHub Pages. Every push to
`main` republishes it.

- `index.html`, `residential.html`, `commercial.html`, `domestic.html`,
  `careers.html` — the site pages
- `site.css`, `site.js`, `img/`, `icons/` — shared styling, script and images
- `old.html` and `_assets/` — backup of the previous Canva-built site
  (view it at `/old.html`; hidden from search engines)
- `preview/` — forwards old preview links to the live pages
